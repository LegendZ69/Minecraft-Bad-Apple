# v1.0.0 — baseline player

Mod version **1.0.0** targets **Minecraft Java Edition 1.21.1**. These are separate
version numbers. This baseline is pinned to commit
`2ec4c20d237a3f3f5d40bd02ffadf545229fc50e`; later implementation and documentation
changes do not change that source snapshot.

## Included

- Fabric client-side video screen with native decoded frame dimensions, source
  timestamps, and nearest-neighbor display.
- Playback, pause/resume, seeking, restart, looping, and session-local screen
  placement, including one source pixel per world block of screen area.
- Local video conversion to seekable `.bapple` archives with lossless RGB PNG
  frames and aligned PCM audio.
- Background decoding with bounded buffering and archive input validation.

This is a rendered screen, not changing world blocks or a vanilla datapack. Other
players do not see or hear this client's local playback. The animation and audio
are not included.

## Verification record

The baseline compiled successfully and all **24 tests passed** in
[GitHub Actions run 34174416502](https://github.com/LegendZ69/Minecraft-Bad-Apple/actions/runs/34174416502).
This is build/unit-test evidence, not an in-game visual or audio verification.
The baseline was not verified against the full Bad Apple!! source media and has
no recorded Minecraft runtime verification in that run.

The release workflow rebuilds this exact historical JAR and repeats its original
9 Python and 15 Java tests. Portable helper tools and documentation are bundled
from the later publication workflow revision; they are individually hashed in
`build-info.json`. The recorded `commit` identifies the JAR source, not a claim
that these later verification helpers existed at the baseline commit. GitHub's
automatic source archives remain the exact baseline tag snapshot.

**Known limitations:** later cloud testing exposed Java Sound seek/buffering
problems and a fixed native-stack decoding limit for large PNG frames in this
implementation. These can interrupt full-length playback. v1.1.0 contains the
fixes and regression checks; use that version for normal playback. This release
preserves a documented historical build, not the recommended current version.

## Download and run

1. Obtain `minecraft-bad-apple-1.0.0.jar` from the
   [v1.0.0 release](https://github.com/LegendZ69/Minecraft-Bad-Apple/releases/tag/v1.0.0),
   or the successful baseline Actions artifact. Do not install a `-sources.jar`.
2. Use Java 21, Minecraft Java 1.21.1, Fabric Loader 0.16.5 or newer, and Fabric
   API for Minecraft 1.21.1. Put the mod JAR and Fabric API in that instance's
   `mods` directory.
3. Obtain an authorized local video file. In the baseline source bundle, run
   `python tools/prepare_video.py "reference.mp4" --output bad_apple.bapple`
   with Python 3.10+, FFmpeg, and ffprobe available.
4. Put the result at `<instance>/badapple/bad_apple.bapple`, start the Fabric
   instance, join a world, and run `/badapple play`.
5. Use `/badapple status` to inspect playback and `/badapple place native` for
   one source pixel per block of screen area.

The release is not a complete media-containing Bad Apple!! installation. Keep
your source media separate; publishing project code does not license that media.
See [reference provenance](../REFERENCE_SOURCES.md) for the distinct official,
original, and user-linked references researched after this baseline.
