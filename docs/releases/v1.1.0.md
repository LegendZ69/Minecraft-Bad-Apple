Mod version **1.1.0** targets **Minecraft Java Edition 1.21.1**, with Java 21,
Fabric Loader 0.16.5 or newer, and Fabric API for Minecraft 1.21.1. It is not a
port to another Minecraft version.

**Release verification status: pending.** This document is prepared before the

- Explicit source selection for the official label upload, original NicoVideo
  animation, and user-linked YouTube reference; no silent substitution.

- Exhaustive archive verification against the local source, with a saved report.
- Clearly synthetic video/audio fixtures for repeatable conversion and runtime
  testing without redistributing the original animation or recording.
- An isolated Minecraft client smoke-test harness and versioned release records.

## Download and run

1. Download `minecraft-bad-apple-1.1.0.jar` from the
   [v1.1.0 release](https://github.com/LegendZ69/Minecraft-Bad-Apple/releases/tag/v1.1.0)
   and put it in the Minecraft instance's `mods` folder alongside Fabric API.
   Install the normal mod JAR, not a sources JAR or test artifact.
2. Download the matching source/tools bundle or check out tag `v1.1.0`. With
   Python 3.10+, FFmpeg, and ffprobe available, prepare and verify an authorized
   local reference:

   ```sh
   python tools/prepare_video.py "reference.mp4" --output bad_apple.bapple
   python tools/verify_archive.py bad_apple.bapple --source "reference.mp4" --report verification.json
   ```

3. Copy `bad_apple.bapple` to `<instance>/badapple/bad_apple.bapple`. Start
   Minecraft Java 1.21.1 with Fabric, join a world, and run `/badapple play`.
4. Use `/badapple status` to inspect playback and `/badapple place native` for
   one source pixel per block of screen area. Pause with `/badapple pause`.

For explicit official-source download options, access limitations, and media
rights boundaries, read [reference sources](../REFERENCE_SOURCES.md). Original
animation/audio is not an asset in this public release; a synthetic fixture is
not the requested Bad Apple!! animation.

## Reproduce the cloud checks

Use JDK 21, Gradle 8.8, Python 3.10+, FFmpeg, and ffprobe. A graphical Minecraft
client also needs an OpenGL-capable display; Linux cloud runs use a virtual
display and software rendering configured by CI.

```sh
gradle build
python -m unittest discover -s tests -v
python tools/generate_fixture.py --output build/synthetic.mkv
python tools/prepare_video.py build/synthetic.mkv --output build/smoke-game/badapple/smoke.bapple
python tools/verify_archive.py build/smoke-game/badapple/smoke.bapple --source build/synthetic.mkv --report build/archive-verification.json
gradle runSmokeClient
```

The smoke harness is isolated in `src/smoke`; it is not part of the installable
mod. The fixture path above is intentional. Run the client under the display
setup used in the workflow, and inspect its saved reports and logs rather than
inferring success merely from a process having started. Preserve the source,
archive, verification report, and runtime evidence together when reproducing a
result.
